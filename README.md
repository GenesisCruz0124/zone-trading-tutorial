# zone-trading-tutorial

Educational static site teaching a structure-based zone trading technique (Fractals + trendline break + demand/supply
zone entry, invalidation, and take-profit zones), with a live embedded TradingView chart for practice.

**Educational content only — not financial advice.**

## Tech stack

- Vite + React + TypeScript + Tailwind CSS
- TradingView Advanced Real-Time Chart widget (no API key required)
- Deploys as a static site (e.g. Vercel)

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build (tsc -b && vite build)
npm run preview  # preview the production build
```
